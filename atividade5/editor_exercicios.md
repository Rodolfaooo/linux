1. O GNU nano é um editor simples e fácil de usar, ideal para iniciantes e edições rápidas. Já o Vim é mais avançado, rápido e poderoso, mas possui 
curva de aprendizado maior por funcionar com modos de operação.
2. O Nano é mais indicado para alterações simples em arquivos, como editar configurações rapidamente. O Vim é melhor para programação, administração 
de sistemas e tarefas que exigem produtividade e navegação rápida em textos grandes.
3. Nano:
Ctrl + O → salvar
Ctrl + X → sair
Ctrl + K → cortar linha
Ctrl + U → colar

   Vim:
i → inserir texto
Esc → voltar ao modo normal
:wq → salvar e sair
dd → apagar linha
yy → copiar linha
p → colar
gg → início do arquivo
G → fim do arquivo
